# Дежурства — Лоджия 4

Система учёта дежурств для лагеря беженцев.

**Стек:** Rust (axum) + SQLite (Diesel) + vanilla HTML/CSS/JS

## Схема проекта

- [[План]] — полный план реализации
- [[План-v2]] — новые фичи: публичный просмотр, админы зданий, временные отсутствия
- [[Схема-БД]] — структура базы данных
- [[API]] — эндпоинты
- [[Фронтенд]] — описание интерфейса
