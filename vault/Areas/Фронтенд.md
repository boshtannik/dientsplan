## Кнопки в шапке

| Кнопка | Действие |
|--------|----------|
| `+ Период` | Создать новый период (название, дата, кол-во дней) |
| `Следующий` | Автоматически создать период сразу после текущего (та же длительность) |
| `Копировать` | Дублировать текущий период в новый |
| `Заполнить` | Автоматически заполнить текущий период по рейтингу |

## Цвета чипов
- **Синий** (`chip-m`) — мужчина, обычное назначение
- **Розовый** (`chip-f`) — женщина, обычное назначение
- **Зелёный** (`chip-replace`) — замена отсутствующему
- **Красный** (`chip-missing`) — незамещённое дежурство (отсутствует замена)
- **Серый** (`chip-absent`) — пометка отсутствия

## Модалки
1. **Назначение** — клик на ячейку → список подходящих людей (по полу), с пометкой отсутствующих
2. **Отсутствие** — кнопка в боковой панели → выбор человека + причина
3. **Новый период** — название, дата, кол-во дней
4. **Новое здание** — название + добавление помещений
5. **Личный профиль** — клик на имя → полная история
6. **Ввод истории** — обычный период с прошлой датой, заполняется кликами. Для переноса бумаги (~1 год)
